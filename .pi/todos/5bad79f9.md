## Goal
The paddle stops feeling like a text editor cursor.

## Runnable outcome
Held-key paddle movement with acceleration, and a degraded but playable mode when the keyboard protocol is unavailable.

## Tasks (PLAN Phase 3)
1. `src/term/input.rs` — push `DISAMBIGUATE_ESCAPE_CODES | REPORT_EVENT_TYPES | REPORT_ALL_KEYS_AS_ESCAPE_CODES` (crossterm); held-key set from `KeyEventKind::{Press, Repeat, Release}` (ADR-0004).
2. Fallback when protocol absent or flags empty: press sets paddle velocity decaying over ~140 ms so autorepeat sustains movement. Forced by `BREAKOUT_INPUT=legacy`.
3. Paddle acceleration, friction, small momentum carried into ball on contact (FR-13).
4. Bindings: `←`/`→` and `h`/`l` move, `Space` launches, `Esc` pauses, `q` quits, `m` mutes, `F3` toggles debug overlay.
5. Pause menu (FR-6): Resume / Restart run / Mute / Quit.

## Test gate
```sh
cargo run --release
BREAKOUT_INPUT=legacy cargo run --release
```

## Pass when
Holding `←` moves paddle smoothly, no autorepeat stutter at start; releasing stops within one frame; key-to-movement latency ≤ 32 ms on debug overlay (NFR-2); legacy mode is *worse but playable* — a full level clearable in it.

## Stop rule
Clear one level in each input mode.

## Not in this phase
Any change to physics constants tuned in Phase 2.
