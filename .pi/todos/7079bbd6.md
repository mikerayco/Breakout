## Goal
A reason to press "again".

## Runnable outcome
An 8-level run with perk choices, a run summary, and progression that persists between launches.

## Tasks (PLAN Phase 8)
1. `src/game/run.rs` — 8-level sequence built from tier pools by the run seed (FR-39). Tier 1 = lv 1–2, tier 2 = lv 3–4, tier 3 = lv 5–6, tier 4 = lv 7–8; sampled without replacement per pool.
2. `src/game/perk.rs` — 12+ perks per FR-41 (from approved TODO perk proposal), each a data-driven modifier applied to `RunModifiers`. No perk special-case in `physics.rs`.
3. Perk offer screen: 3 of unlocked pool (or fewer per <3 rule), keyboard selection (FR-40). Layout from approved TODO screen-layout proposal.
4. Run summary screen (FR-42) + shard award (FR-43). Layout from approved proposal.
5. `src/save/mod.rs` — JSON profile, atomic write (temp + fsync + rename), corruption recovery by renaming aside (FR-44), `--reset-profile` with `y/N` confirmation (FR-45). `schema_version` first field; unknown version renamed aside.
6. Unlock table (from approved TODO unlock-table proposal): which perks + starting modifiers each shard threshold opens.
7. Determinism test: scripted run, fixed seed, recorded input log → byte-identical summary (NFR-10, same-machine) via headless replay harness.

## Test gate
```sh
cargo test
cargo run --release -- --seed 7    # play a full run to the summary
cat "${XDG_CONFIG_HOME:-$HOME/Library/Application Support}/breakout/profile.json"
echo 'garbage' > "$HOME/Library/Application Support/breakout/profile.json"
cargo run --release                # recovers, does not crash
cargo run --release -- --reset-profile
```

## Pass when
Full run reaches summary; shards accumulate across two runs; an unlock appears after crossing its threshold; corrupt profile renamed aside and play continues; `--reset-profile` asks before wiping; determinism test passes.

## Stop rule
Three consecutive runs with different seeds, no crash, no lost progress.

## Not in this phase
Balance tuning beyond obvious brokenness. Balance is Phase 9.

## Depends on
The three Phase-8 proposals (perk table, unlock table, screen layouts) being approved first.
