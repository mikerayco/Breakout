## Review-gated deliverable owed to Mike before Phase 8 builds.

Per PRD §8 "Additional clarifications" (2026-08-29): the agent proposes a complete 12+ perk table for Mike's review before Phase 8.

## Scope
- 12+ perks (PRD FR-41), each: `{ id, name, one-line description, fn apply(&mut RunModifiers) }`.
- ADR-0008 names ~6 examples: Overclock (`ball_speed_mul`, `score_mul`), Second Serve (`life_refund_per_level`), Shrapnel (`shrapnel_on_break`), Magnet (`magnet_strength`), Glass Cannon (`starting_lives`, `score_mul`), Long Fuse (`powerup_duration_mul`). Define the rest.
- **Each perk is a modifier on `RunModifiers`, not a branch in `physics.rs`** (AGENTS §3, ADR-0008). If a perk can't be expressed as an existing axis, propose a *new modifier axis* explicitly (with the small deliberate sim code it needs) — do not special-case.
- Document which axis each perk touches and how multiple perks compose (multiply for multiplicative axes, add for additive).

## Constraint
No perk may add an `if perk == ...` branch in `physics.rs`. Adding a new `RunModifiers` axis is allowed but must be called out in the proposal.

## Done when
Mike approves the 12+ perk table and any new axes.
