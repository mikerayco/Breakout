## Review-gated deliverable owed to Mike before Phase 8 builds.

Per PRD §8 "Additional clarifications" (2026-08-29): the agent proposes the shard unlock table for Mike's review before Phase 8.

## Scope (PRD FR-43, ADR-0008 "Meta progression")
- Shard award formula per run (function of levels cleared, bricks destroyed, best combo).
- Threshold table: which shard totals unlock which perks and starting modifiers.
- **Unlocks only ever add options; they never make a run easier by default** (ADR-0008). A fresh profile and a veteran profile play the same game with different menus.
- Specify the initial unlocked pool (what a brand-new profile can be offered) vs what stays locked.

## Constraint
The first few runs have a smaller perk pool (ADR-0008 accepted consequence). Perk offer when unlocked pool minus taken perks < 3: offer all available (fewer than 3 cards); never re-offer taken perks (resolved 2026-08-29).

## Done when
Mike approves the shard award formula + threshold/unlock table + initial pool.
