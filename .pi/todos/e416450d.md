## Goal
Sound that adds to the feel and never gets in the way.

## Runnable outcome
The game sounds like something.

## Tasks (PLAN Phase 7)
1. `src/audio/mod.rs` — kira setup behind a `Sound` trait so the subsystem can be replaced by a no-op (FR-49).
2. The ten effects in FR-46, loaded from `assets/audio/` as **WAV** (kira decodes WAV natively; no decoder dep — ADR-0005), compiled in with `include_bytes!`. (From TODO asset-sourcing.)
3. Music bed on its own track, ducked during hit-stop (FR-47).
4. Pitch-shift brick-hit effects by combo so a long combo rises in pitch.
5. `m` toggle, persisted; `--no-audio` (FR-48). Mute state readable at a glance in HUD.
6. Startup must not block on audio device enumeration; initialise off the main loop.

## Test gate
```sh
cargo run --release
cargo run --release -- --no-audio
# Linux, no audio device:
PULSE_SERVER=/nonexistent cargo run --release ; echo "exit=$?"
```

## Pass when
Effects fire on the right events with no audible latency; music bed sits under effects; `m` mutes instantly and state survives restart; no audio device → plays silently, reports in `--caps`, exits 0; startup < 300 ms (NFR-7).

## Stop rule
Play one level muted and one unmuted; the muted run must not stutter differently.

## Not in this phase
Any music composition beyond the sourced CC0 bed (OQ-5 resolved).
