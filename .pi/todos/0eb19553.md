## Goal
A boring but correct Breakout. Correctness first, feel later.

## Runnable outcome
A single hard-coded level you can actually clear or lose.

## Tasks (PLAN Phase 2)
1. `src/game/tuning.rs` — every constant, one file, documented units (PRD FR-22). (After TODO tuning proposal approved.)
2. `src/game/state.rs` — `GameState { Title, Playing, Paused, LevelClear, RunOver }` + transitions.
3. `src/game/physics.rs` — **swept** circle-vs-AABB collision with iterative time-of-impact within the tick; walls, paddle, bricks (FR-16). Paddle english + min-vertical-angle clamp (FR-15). No perk/powerup special-cases (AGENTS §3).
4. Fixed-timestep 240 Hz sim, accumulator, max catch-up 5 (ADR-0006).
5. Brick grid HP 1–5, steel, explosive (FR-17/18/19); scoring, lives, combo (FR-23), speed ramp (FR-22).
6. Draw as flat rectangles + flat circle. No particles/glow/shake.
7. `src/game/rng.rs` — seeded deterministic RNG threaded through sim (NFR-10, same-machine scope). Never reads clock or global RNG.
8. Unit tests: tunnelling at max speed, corner-case brick collisions, angle clamp, explosive chain termination, combo reset, deterministic replay of recorded input vector via headless replay harness (OQ-7 = yes).

## Test gate
```sh
cargo test
cargo run --release
cargo run --release -- --seed 42     # twice; identical brick drops and outcomes
```

## Pass when
`cargo test` passes incl. tunnelling + determinism; a level can be cleared; 3 lost balls end the run; the ball never escapes the playfield, sticks to a wall, or enters a horizontal loop over 5 min; two `--seed 42` sessions with same inputs produce the same score.

## Stop rule
Ten minutes of continuous play with no ball escape and no panic.

## Not in this phase
juice, powerups, level files, audio, perks, save data.
