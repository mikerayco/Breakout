## Goal
The board gets chaotic in a good way.

## Runnable outcome
All seven powerups obtainable and visibly working.

## Tasks (PLAN Phase 6)
1. `src/game/powerup.rs` — seven types in FR-32, drop chance from `tuning.rs`, capsule fall physics, paddle collection (FR-31).
2. Multiple balls: convert single-ball field into a small `Vec<Ball>` with **hard cap = 8** (resolved 2026-08-29; matches NFR-1 stress test); a life lost only when the last ball is gone (FR-34).
3. Independent timers with HUD indicators and refresh-not-stack semantics (FR-33).
4. Laser projectiles, sticky catch-and-release, wide paddle, slow-mo, pierce.
5. Debug spawner (`F5` cycles + spawns chosen powerup) so the gate is testable in seconds.

## Test gate
```sh
cargo test
cargo run --release
# F5 through all seven; then play a normal level
```

## Pass when
Each of the seven behaves as specified; multiball with 8 balls + particles stays inside NFR-1; re-collecting a timed powerup refreshes rather than doubles; no powerup leaves permanent state after its timer ends; losing the last ball with a Wide paddle active resets the paddle correctly on the next life.

## Stop rule
One level cleared using only powerups triggered naturally, no debug spawner.

## Not in this phase
Perks (they come with the run structure in Phase 8).
