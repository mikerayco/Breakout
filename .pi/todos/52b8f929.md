## Goal
Put a real, moving, GPU-composited image in the terminal at 60 fps. The riskiest phase; deliberately second.

## Runnable outcome
`breakout` shows an animated test card — scrolling gradient, bouncing AA circle, colour-bar strip, live FPS/frame-time overlay — filling the terminal.

## Tasks (PLAN Phase 1)
1. `src/render/framebuffer.rs` — RGB (`f=24`) buffer `320·S × 240·S`; `clear`, `pixel_mut`, `as_bytes()`. `S` per ADR-0003.
2. Wire tiny-skia as rasteriser into that buffer; draw test card (gradient, AA circle, rects).
3. `src/render/text.rs` — hand-rolled 5×7 bitmap font (uppercase, digits, `:./×%-`). No font crate.
4. `src/term/shm.rs` — POSIX shm transport per ADR-0002: `shm_open` uniquely named, `ftruncate`, `mmap`, write, `munmap`/`close`, emit `\x1b_Ga=T,f=24,s=<w>,v=<h>,t=s,i=<id>,p=1,q=2,C=1;<base64(name)>\x1b\\`; rotate 3 names.
5. `src/term/kgp.rs` — fallback `t=d` transport (4096-byte base64 chunks, `m=1`/`m=0`); auto on shm fail; forced by `BREAKOUT_TRANSPORT=direct`.
6. Double-buffer image ids (`i=1`/`i=2`): transmit new, then delete previous. Never delete before transmit (ADR-0002).
7. Frame pacing: 60 Hz presentation clock, drops never queues (FR-9).
8. Handle `SIGWINCH`/crossterm resize: recompute `S`, reallocate, delete images, redraw (FR-10). Too-small screen (FR-11).
9. Overlay: fps, p50/p99 frame time, transport (shm/direct), scale factor, image size.

## Test gate
```sh
cargo run --release                            # watch 30s in Ghostty
BREAKOUT_TRANSPORT=direct cargo run --release  # fallback renders
cargo run --release -- --scale 2               # forced scale honoured
```
Resize slowly/quickly both dims; shrink below minimum.

## Pass when
p99 frame time ≤ 16.6 ms and ≥ 55 fps on shm (NFR-1); smooth motion, no tearing/flicker; resize leaves no stale band; too-small screen appears and recovers; `direct` renders (may be slower — record); after `q` no leftover image in scrollback.

## Stop rule
p99 written into `docs/PERF.md` before Phase 2. If shm cannot hit the budget, stop and ask — that invalidates ADR-0002.

## Not in this phase
paddles, balls, bricks, input beyond `q`, audio.
